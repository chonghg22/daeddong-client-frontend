# 공중화장실 API 참고값

행정안전부 `공중화장실정보 조회서비스` 연동 시 바로 쓰는 참고값이다.

## 주요 응답 컬럼

- `OPN_ATMY_GRP_CD`: 개방자치단체코드
- `MNG_NO`: 관리번호
- `RSTRM_NM`: 화장실명
- `LCTN_ROAD_NM_ADDR`: 소재지도로명주소
- `LCTN_LOTNO_ADDR`: 소재지지번주소
- `MALE_TOILT_CNT`: 남성용 대변기 수
- `MALE_URNL_CNT`: 남성용 소변기 수
- `MALE_FRDBL_TOILT_CNT`: 남성용 장애인용 대변기 수
- `MALE_FRDBL_URNL_CNT`: 남성용 장애인용 소변기 수
- `FEMALE_TOILT_CNT`: 여성용 대변기 수
- `FEMALE_FRDBL_TOILT_CNT`: 여성용 장애인용 대변기 수
- `MNG_INST_NM`: 관리기관명
- `TELNO`: 전화번호
- `OPN_HR`: 개방시간 구분
- `OPN_HR_DTL`: 개방시간 상세
- `WGS84_LAT`: 위도
- `WGS84_LOT`: 경도
- `EMRGNCBLL_INSTL_YN`: 비상벨 설치 여부
- `RSTRM_ENTRAN_CCTV_INSTL_EN`: 출입구 CCTV 설치 여부
- `DIAP_EXCHCON_EN`: 기저귀교환대 여부
- `DAT_CRTR_YMD`: 데이터기준일자
- `DAT_UPDT_PNT`: 데이터갱신시점
- `LAST_MDFCN_PNT`: 최종수정시점
- `BSS_STT_NM`: 영업상태코드명
- `SE_NM`: 구분명

## 영업상태코드

- `01`: 영업/정상
- `02`: 휴업
- `03`: 폐업
- `04`: 취소/말소/만료/정지/중지
- `05`: 제외/삭제/전출
- `06`: 기타

## 전체 자치단체 코드

- `6110000_ALL`: 서울특별시 전체
- `6260000_ALL`: 부산광역시 전체
- `6270000_ALL`: 대구광역시 전체
- `6280000_ALL`: 인천광역시 전체
- `6290000_ALL`: 광주광역시 전체
- `6300000_ALL`: 대전광역시 전체
- `6310000_ALL`: 울산광역시 전체
- `5690000_ALL`: 세종특별자치시 전체
- `6410000_ALL`: 경기도 전체
- `6530000_ALL`: 강원특별자치도 전체
- `6430000_ALL`: 충청북도 전체
- `6440000_ALL`: 충청남도 전체
- `6540000_ALL`: 전북특별자치도 전체
- `6460000_ALL`: 전라남도 전체
- `6470000_ALL`: 경상북도 전체
- `6480000_ALL`: 경상남도 전체
- `6500000_ALL`: 제주특별자치도 전체

## 현재 연동에서 바로 쓰는 규칙

- 외부 고유키는 `MNG_NO`를 우선 사용
- 주소는 `LCTN_ROAD_NM_ADDR` 우선, 없으면 `LCTN_LOTNO_ADDR`
- 운영시간이 `상시`면 앱 저장값은 `00:00 ~ 24:00`로 정규화
- 장애인 화장실 여부는 장애인용 칸수 합계가 1개 이상이면 `Y`
